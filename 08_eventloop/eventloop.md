Eventloop - это бесконечный цикл, который координирует работу однопоточного рантайма,
управляя порядком выполнения синхронного и асинхронного кода. Его основная функция -
непрерывно маниторить состояние стека вызовов (Call Stack) и переносить в него готовые
к выполнению задачи из соответствующих очередей в строго определенном порядке приоритета.

Ключевые компоненты и порядок обработки:

1. Call Stack - выполняет синхронный кода
2. Микрозадачи (Microtask Queue) - очередь для обработки вызовов из промисов
   (Promise.then/catch/finally), queueMicrotask(), MutationObserver.
   Обрабатывается полностью после каждой микрозадачи, перед рендерингом
   и следующей макрозадачей.
3. Макрозадачи (Macrotask Queue / Task Queue) - очередь для
   setTimeout, setInterval, setImmediate, обработки событий (click, keydown),
   I/O-операций, requestAnimationFrame. Обрабатывается по одной задаче за цикл.
4. Рендеринг (в браузере) - обновление UI происходит после очистки очереди микрозадач,
   но перед следующей макрозадачей (если браузеру нужно перерисовать кадр).

Алгоритм одного цикла (tick) Eventloop:

1. Выполнить весь синхронный код в Call Stask до его опустошения.
2. Выполнить все микрозадачи и Microtask Queue (если они есть), пока очередь не опустеет.
3. При необходимости выполнить рендеринг.
4. Извлечь и выполнить одну макрозадачу из Macrotask Queue.
5. Вернуться к 1 шагу.

Таким образом Eventloop - это менеджер выполнения, гарантирующий неблокирующую
асинхронность через цикличную обработку очередей с четкой иерархией приоритетов.
